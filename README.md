# 🎲 Python Digital Dice

A simple beginner-friendly Python project that simulates rolling a physical six-sided dice.

## About

This project generates a random number between 1 and 6, just like rolling a real dice.

## Technologies Used

- Python
- Random module

## How to Run

1. Make sure Python is installed on your computer.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run:

```bash
python dice.py
```
